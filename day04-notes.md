
# Day 4 - DevOps & Agile

Agile and DevOps are two different concepts but they work together.

Agile means giving small updates quickly, instead of one big release. A new version 
comes every week or month. Its goal is to give the end user the best experience.

DevOps means the dev and ops teams working together, so that work becomes fast and 
automated.

Agile wants quick feedback from the customer, but this is only possible because of 
DevOps, since DevOps creates a fast environment.

## Difference between the two:
- Agile focuses on the end user and developer, DevOps focuses on the dev and ops team
- Agile has fixed frameworks like Scrum, Kanban, DevOps doesn't have a fixed 
  framework, just practices like automation, monitoring
- Agile tools - JIRA, Trello, Slack
- DevOps tools - Jenkins, GitHub Actions

## How to use both together:
1. Bring the dev and ops teams together
2. Give DevOps tasks the same importance as development tasks
3. Include QA at every stage
4. Automate whatever can be automated
5. Check progress using numbers
