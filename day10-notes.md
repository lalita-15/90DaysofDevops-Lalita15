## What I Learned

Today I learned how Python projects are organized and different ways to execute Python programs. Understanding project structure is important for writing maintainable and scalable automation scripts in DevOps.

## Python Project Structure

A typical Python project may contain:

```text
project/
│
├── main.py
├── requirements.txt
├── modules/
├── scripts/
└── README.md
```

### Purpose of Each File

* **main.py** → Main entry point of the application
* **requirements.txt** → Stores project dependencies
* **modules/** → Reusable Python code
* **scripts/** → Automation scripts
* **README.md** → Project documentation

## Running Python Programs

Execute a Python script using:

```bash
python main.py
```

Check Python version:

```bash
python --version
```

Install required packages:

```bash
pip install -r requirements.txt
```

## Why Project Structure Matters?

* Better code organization
* Easier maintenance
* Improved collaboration
* Reusable modules
* Faster troubleshooting
