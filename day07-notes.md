# Day 6 : The Big Picture: Learning a Programming Language

Today, I learned that to become a successful DevOps Engineer, it is very important to have a basic understanding of at least one programming language. The true purpose of learning programming is not to become a software developer, but to understand automation, troubleshoot issues, and work effectively with DevOps tools.

Why Programming is Important in DevOps?
- To write automation scripts
- For debugging and trobleshooting
- To understand Devops tools
-  To make easy Infrastructure

Python vs Go
Python 
- Easy to learn
- Popular for automation and scripting
- Best choice for beginners

Go
- Fast performance
- Easy deployment (single binary)
- Most of the devops tools written in Go like Kubernetes, Docker, Prometheus aur Grafana etc.
- High demand in Cloud-native ecosystem
