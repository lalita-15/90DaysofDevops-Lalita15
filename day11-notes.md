# Day 11 - Variables, Constants & Data Types in Python

## What I Learned

Today I learned about Variables, Constants, and Data Types in Python. These are the building blocks of any program and are used to store and manage data efficiently.

## Variables

Variables are used to store values that can change during program execution.


challenge = "#90DaysOfDevOps"
days_completed = 11


## Constants

Python does not have true constants, but by convention we write them in uppercase.

```python
TOTAL_DAYS = 90
```

## Using Variables in a Program

```python
challenge = "#90DaysOfDevOps"
TOTAL_DAYS = 90
days_completed = 11

print("Welcome to", challenge)
print("This is a", TOTAL_DAYS, "day challenge")
print("You have completed", days_completed, "days")
```

### Output

```text
Welcome to #90DaysOfDevOps
This is a 90 day challenge
You have completed 11 days
```
