# Day 1 - Introduction to DevOps

Devops: 
Devops is a mindset that brings together Development and Operations teams so the software can be designed and delivered to users more quickly

Key Points: 
- Devops is not a software nor a programming language
- Devops breaks down the walls of Development, Operations and QA teams.
- Goal - To reduce the time of software release years to weeks/days.
- Automation is the most important part of Devops
