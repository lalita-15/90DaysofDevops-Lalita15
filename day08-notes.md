# Day 8 - Setting up Python Environment & Hello World

## What I Learned

Today I set up my Python development environment and created my first Python program. Python is one of the most widely used programming languages in DevOps because of its simplicity, automation capabilities, and strong cloud support.

## Installing Python

I installed Python on my workstation from the official Python website and verified the installation using:

python --version


I also verified that pip was installed correctly:

pip --version


## Setting up VS Code

I used Visual Studio Code (VS Code) as my IDE and installed the Python extension to enable code execution, debugging, and IntelliSense support.

## Creating My First Python Program

Created a file named:
first-program.py


Added the following code:

print("Hello #90DaysOfDevOps")


Run the program using:

python hello.py

Output:

Hello #90DaysOfDevOps
