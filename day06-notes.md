# Day 6  : DevOps - The real stories


## What I learned today:
Big companies like Amazon, Netflix, and Etsy successfully use DevOps in real life.

## Amazon
In 2010, Amazon moved from physical servers to AWS cloud. In 2011 they adopted 
continuous deployment, where developers could deploy code anytime, to any server. 
This let them deploy new code to production in an average of just 11.6 seconds.

## Netflix
Netflix developers can build their code into deployable images automatically, 
without depending on IT operations. They use Continuous Monitoring - if a deployment 
fails, it automatically rolls back to the previous version and reroutes traffic.

## Etsy
Etsy used to struggle with slow, painful deployments and team silos. Around 2009, 
they let developers deploy their own code. This made developers take responsibility 
for app performance and uptime too. Key lesson: even failure can be a success if you 
learn from it - this is part of DevOps culture.

## Recap of Days 1-6:
- DevOps combines Development and Operations so one team can manage the whole 
  application lifecycle: Development, Testing, Deployment, Operations
- The main goal of DevOps is to shorten the development lifecycle while delivering 
  features and fixes frequently, in line with business goals
- DevOps is also referred to as Continuous Development, Testing, Deployment, and 
  Monitoring
