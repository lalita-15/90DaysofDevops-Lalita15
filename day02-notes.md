# Day 2 - Responsibilities of a DevOps Engineer

Devops Engineer has to understand two parts of application:
1. Development - How developers write code
2. Operations - How to maintain and deploy application on server

Key Points: 
- DevOps Engineer should know the entire process from application development to deployment
- Need to setup application - on-premises, cloud, or serverless
- Need to know basic knowledge of Linux because servers usually run on Linux
- Basic knowledge of networking (DNS, DHCP, Load Balancing)
- Today most of the applications run on containers like Docker

## Jack of all trades, Master of none:
It's means - You should have basic/foundational knowledge of coding, networking, servers don't need to be expert just enough to be able to connect everything together and keep things running smothly.

## Main important task: 
The main core job of Devops Engineer is to release new feature and fix bugs into application - but this has to be continuosly (again and again), in an automated way (using scripts/tools), and along with testing. It's not something you do just once and stop — this same process repeats with every release
