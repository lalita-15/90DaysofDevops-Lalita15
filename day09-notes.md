## Key Concepts Learned

### Python is an Interpreted Language

Unlike compiled languages, Python executes code line by line through an interpreter, making it easy to write and test programs.

### print() Function

The `print()` function is used to display output on the terminal or console.

### Program Execution

When the Python interpreter runs a script, it reads each line and executes it sequentially.
